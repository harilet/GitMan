# GitWeft

GitWeft is a fast desktop Git client built with **Tauri 2**, **Rust**,
**SvelteKit 5** and **TypeScript**.

> **LLM note:** This project was developed with the assistance of an LLM, and
> this README was generated by an LLM. Review the code and documentation before
> relying on them in production.

The app combines `git2` (libgit2) for fast local repository operations with the
system `git` binary for network operations, so SSH agents, credential helpers and
existing Git configuration work as expected.

Repository: [github.com/harilet/git-gui]([https://github.com/harilet/GitWeft](https://github.com/harilet/GitWeft))

## Features

### Repositories

- Open, initialize and clone repositories
- Recent projects with pinning and one-click access
- Multiple repositories open at once as independent tabs
- Custom frameless window with a built-in title bar

### Working tree and commits

- Staged / unstaged file lists with status codes
- Stage, unstage, discard, stage-all and unstage-all (including deletions)
- Per-file and per-commit diff viewer with inline highlighting
- Commit with a message, plus `Ctrl/Cmd + Enter`
- Settings dialog with **appearance** (accent color) and **Git identity** (local or global)

### History and graph

- Commit history with author, time, short SHA and ref badges
- Filter by message, author or SHA
- Paginated history (300 commits per page, with **Load more**)
- Branch topology graph with fork/merge relationships
- Optional remote-tracking branches in the graph

### Branches

- Local and remote branch lists
- Per-branch upstream plus ahead/behind counts
- Create, checkout, merge and delete branches
- Safe delete for merged branches; explicit force for unmerged ones
- Checkout a remote branch and create a tracking branch automatically

### Remotes, tags and stashes

- Add/remove remotes and fetch/pull/push (single remote or all)
- Fetch and pull use `--prune` to remove stale remote-tracking branches
- Auto-fetch on project open (throttled to once every five minutes)
- Push targets the current branch's upstream remote; sets upstream when needed
- Live clone/fetch/pull/push progress in the toolbar
- Create/delete lightweight and annotated tags (target any SHA or ref)
- Create, apply, pop and drop stashes (untracked files included)

### Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd + R` | Refresh the current project |
| `Ctrl/Cmd + Enter` | Commit staged changes |
| `Esc` | Close the active dialog |

- **Node.js 20+** and npm
- **Rust** (stable toolchain)
- **Git** available on `PATH`
- Tauri system dependencies for your platform:
  [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/)

`build-essential`, `curl`, `wget`, `file`, `libxdo-dev`, `libssl-dev`,
`libayatana-appindicator3-dev` and `librsvg2-dev`.

## Getting started

```bash
git clone git@github.com:harilet/git-gui.git
cd git-gui
npm install
npm run tauri dev
```

Build a release bundle (currently configured for `deb`):

```bash
npm run tauri build
```

## Architecture notes

- Backend commands are **stateless**: each receives the target repository path,
  so multiple projects can be driven concurrently.
- Commands are registered with `#[tauri::command(async)]` and run off the UI
  thread, keeping the window responsive during large operations.
- Network commands (`clone`, `fetch`, `pull`, `push`) shell out to `git` and
  stream progress to the frontend via the `git-progress` event.
- `get_snapshot` returns status, log, branches, graph, remotes, tags, stashes and
  user config in one call, avoiding repeated repository scans during refresh.
- `git2` is built without bundled TLS/SSH because all network traffic goes
  through the system `git` binary.
